# burp-pro
## prerequisites
java 21 (exact version)

## installation steps
```
git clone https://github.com/abizekv/burp-pro.git
cd burp-pro
chmod +x install.sh
sudo ./install.sh
```

## fix icon for gnome
```
sudo cp icon.svg /usr/share/burpsuitepro/
cp burpsuitepro.desktop ~/.local/share/applications
